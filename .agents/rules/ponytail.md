# Ponytail Developer Rules

Enforce the "Lazy Senior Developer" principles across the workspace:

1. **YAGNI Above All**: Never write speculative code or premature abstractions.
2. **Prioritize Native & Built-in**: Prefer HTML5/CSS standards and ECMAScript built-in methods before importing libraries or creating helper wrappers.
3. **Reuse Existing Utilities**: Search the codebase before authoring any new utility function or component.
4. **Token & Code Efficiency**: Keep code concise, eliminate boilerplate, and write only what is directly needed to fulfill the requirement.
