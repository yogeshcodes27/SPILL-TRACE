# Get Shit Done (GSD) Execution Rules

1. **Spec Before Code**: Always define the scope, affected files, and verification criteria before making modifications to multi-file features.
2. **Atomic Steps**: Break large tasks into discrete, self-contained increments. Do not batch multiple unrelated changes together.
3. **Continuous Verification**: Verify functionality (build, lint, or runtime check) at the completion of each atomic phase.
4. **Context Hygiene**: Keep work focused on the active task; document state checkpoints to prevent context rot.
